# FPGA License Plate Recognition (LPR)

## Overview
This project is an FPGA-based License Plate Recognition (LPR) system implemented using Verilog in Vivado.

The design includes:
- Verilog RTL modules
- 7-segment display output
- FPGA implementation flow
- Plate data processing logic

## Project Status
🚧 This project is currently under development.

The current implementation is functional at RTL level, but the final hardware output is still being verified and improved.

## Tools Used
- Xilinx Vivado
- Verilog HDL
- realdigital boolean board

## Files Included
- LPR_top.v
- LPR.v
- seg7_controller.v
- plate.coe
- convert.py
